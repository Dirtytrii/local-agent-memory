# Editorial Style & Evidence Source Rules

- **Source Separation**: Clearly label firsthand work (`BUILT` / `MEASURED` / `LIVED`) vs external references (`EXTERNAL` / `DEMO`). Never present external benchmarks as personal measurements.
- **Concrete Openings**: Start technical articles with a real failure, command output, or trade-off — never generic "In today's fast-paced AI era..." intros.
- **Publishing Gate**: Always leave drafts local until explicit human confirmation before publishing.
